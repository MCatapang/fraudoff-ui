# Architecture Overview

**Last updated:** 2026-03-14

---

## Purpose

FraudOff is an AI-powered fraud detection and prevention service for everyday consumers. The web client (`fraudoff-ui`) provides a dashboard-centric interface where users monitor transactions, review alerts, and receive proactive security coaching across all their linked financial accounts. See [product-vision.md](../product-vision.md) for the full product definition.

---

## High-Level System Diagram

```
┌─────────────────────────────────────────────────────┐
│                    Browser (Client)                  │
│                                                     │
│  React hydration layer                              │
│  Client components: NavigationBar, ModeToggle,      │
│  ItemCarousel, UserAuthForm, Dashboard widgets      │
└──────────────────────┬──────────────────────────────┘
                       │ HTTP / RSC streaming
┌──────────────────────▼──────────────────────────────┐
│               Next.js App Router (Server)            │
│                                                     │
│  Server Components: layouts, pages, CardGrid,       │
│  MainBanner                                         │
│                                                     │
│  Middleware: token checks for protected routes      │
└──────────────────────┬──────────────────────────────┘
                       │ REST (JSON) + OpenAPI contract
┌──────────────────────▼──────────────────────────────┐
│               fraudoff-api (.NET / C#)               │
│                                                     │
│  REST controllers, Cognito auth, Cedar authz,       │
│  EF Core + PostgreSQL (prod + local dev via Docker)  │
└─────────────────────────────────────────────────────┘
```

The UI does **not** have its own database. All persistent data lives in the API. The UI communicates with the API via typed REST calls generated by orval from the OpenAPI spec.

## Deployment Target

- **UI**: AWS Amplify Hosting (Next.js SSR, preview deploys per PR, CI/CD from GitHub)
- **API**: AWS App Runner (containerized .NET, auto-scaling)
- **Networking**: Both behind CloudFront with path-based routing — same origin, no CORS
- **Other AWS services**: Cognito (auth), Secrets Manager (secrets), RDS (PostgreSQL), Verified Permissions (Cedar)
- Preview deployments on every PR (Phase 4)
- Production deploy on release tag

See [ADR-004](../adr/adr-004-solution-architecture.md) for the deployment topology decision.
